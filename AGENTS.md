This repository is «Проба 3D» (`probe-3d`), a measurement app of the «Горница» studio, not a game: it answers whether a
phone can draw the studio's 3D — the hall and the animated Rocketbox people of `Nefeste/bolnitsa` — and by which path:
Three.js on WebGL (`expo-gl`), Three.js on WebGPU (`react-native-webgpu`), or sprites pre-rendered by Three.js and drawn by
Skia. Owner's decisions: `Nefeste/uprava` issues #68, #69, #71 (07.11.2026). The live specification is `docs/spec.md`.

## Studio charter — read first

This project belongs to the «Горница» studio. Studio-wide rules live only in the public
charter repository `Nefeste/gornitsa` (https://github.com/Nefeste/gornitsa); this repository
keeps only what is specific to the project. Before changing anything — and after a context
reset — read the charter's `AGENTS.md`, then `docs/05-rules.md` (hard rules for every game)
and `docs/04-process.md` (how work is done). Raw files:
`https://raw.githubusercontent.com/Nefeste/gornitsa/main/<path>`.

Current state of this project: `STATUS.md` (it is not repeated here).

Precedence: the owner's recorded decision → the charter → this project's documents. A project
rule may narrow a charter rule, never weaken it. If a document here restates or contradicts
the charter, replace it with a link or report the contradiction to the owner.

## Expo and native SDKs

Expo SDK 57, as the sister projects (`package.json`). Never write Expo, React Native, Skia, `react-native-webgpu`,
`expo-gl` or Three.js code from memory — follow «Expo has changed» in the charter's `AGENTS.md`; Three.js is pinned
(0.184.0, the version `react-native-webgpu`'s example runs).

## Commands

```bash
npm ci
npx expo install <package>          # ALWAYS instead of npm add for Expo/RN packages
npm run typecheck                   # tsc (app) + tsc -p tools
npm run lint                        # zero warnings
bun test tools/test                 # projection, crowd, people file, sprites, stats, passport
npm run export:web && npm run e2e   # web build + the browser scenario (all six steps, ?quick); screenshots in tools/e2e/out
python blender/build.py             # the hall: assets/models/hall.glb, src/art/hall.gen.ts (bpy==4.5.15, Python 3.11)
bun tools/people/pack.ts            # the people: assets/people/people.bin from assets/rocketbox (bolnitsa's bake code)
bun tools/bake/run.ts [preview|gpu|skia]   # Chromium without a window: report shots, Skia background and sprite atlas
```

Chromium: `CHROMIUM_PATH` or `/opt/pw-browsers/chromium`. A regenerated file changes its SHA-256 in `assets/LICENSES.md`
(`tools/test/passport.test.ts` checks it). Run typecheck, lint, tests and the browser scenario before every push.
The APK is built only on a `vX.Y.Z` tag (`.github/workflows/android.yml`; tags are the owner's), signed with the React
Native debug key: the probe never goes to a store.

## Map

- `src/sim/` — pure TypeScript: `crowd.ts` (people walk and stand, seeded), `camera.ts` (one camera; Skia projects with it),
  `stats.ts`, `bench.ts` (the six steps, warm-up 90 and 600 measured frames).
- `src/people/` — `bake.ts` and `cast.ts` copied from `Nefeste/bolnitsa` (source line on top); `pack.ts` — the phone file.
- `src/scenes/` — `hall.ts` (shared), `gl/` (WebGLRenderer, bolnitsa's GLSL skinning from the bone texture), `gpu/`
  (WebGPURenderer, the same skinning in TSL; poses are instance attributes, not `InstancedMesh`), `skia/` (picture per
  frame: background + one `drawAtlas`), `loop.ts`.
- `src/art/` — `palette.ts`, `sprites.ts` (atlas layout), `hall.gen.ts` (generated by Blender — never edit by hand).
- `src/ui/`, `App.tsx` — menu, «Замер всего», live view, results table; strings — `src/i18n/`.
- `blender/`, `tools/people/`, `tools/bake/`, `tools/e2e/`, `tools/test/`.
